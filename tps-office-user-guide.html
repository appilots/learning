2การเข้าสู่ระบบ

ระบบใช้บัญชี Microsoft 365 (O365) ของบริษัทในการยืนยันตัวตน ผ่าน Single Sign-On เดียวกับที่ใช้ล็อกอิน Outlook/Teams ทุกวัน ไม่มีรหัสผ่านชุดที่สองให้จำเพิ่ม

  1. เข้าเว็บไซต์ https://tpsit.attg.co.th จะเห็นหน้าแนะนำระบบพร้อมปุ่ม "ลงชื่อเข้าใช้ด้วย Microsoft 365"
  2. กดปุ่มแล้วเลือกบัญชี O365 ของบริษัท (เช่น 0158-ATA@ap01.aisingroup.com) จากหน้า "Pick an account"
  3. ระบบอาจพาไปหน้า Login ของ AISIN (SSO) ให้กรอก Username/Password บัญชีเดิมที่ใช้ล็อกอินเครื่องทุกวัน
  4. เมื่อยืนยันตัวตนสำเร็จ ระบบจะพาเข้าหน้าหลักอัตโนมัติ — สิทธิ์การใช้งานจะถูกกำหนดตามอีเมลที่ login โดยอัตโนมัติ
ไม่ต้องขอ Account แยกต่างหาก ใช้บัญชีที่ล็อกอิน Outlook/Teams ทุกวันได้เลย

5Project Registration

ใช้ลงทะเบียนโครงการ Automation ที่ลดเวลาทำงานหรือลดการใช้กระดาษ — มีตัวกรองบริษัท/แผนก/สถานะ/หมวดหมู่ และช่องค้นหา

5.1 ลงทะเบียน Project ใหม่

  1. กดปุ่ม "+ เพิ่ม Project" มุมขวาบน
  2. กรอกส่วน "ข้อมูลโครงการ": ชื่อ Project, ชื่อย่อ, บริษัท, หมวดหมู่ (ลดเวลา/ลดกระดาษ), แผนก/ส่วน/ฝ่าย, และเลือกว่าต้องการใช้ฐานข้อมูล SharePoint List ส่วนกลางหรือไม่
  3. ส่วน "ผู้เกี่ยวข้อง" — ผู้จัดสร้าง (เติมชื่อผู้ล็อกอินอัตโนมัติ) และผู้อนุมัติระดับ Section/Department
  4. ส่วน "สถานะและกำหนดการ" — สถานะ, % ความคืบหน้า, วันเริ่มต้น/สิ้นสุดโครงการ
  5. ส่วน "ผลลัพธ์และเครื่องมือ" — กรอกเฉพาะฟิลด์ที่ตรงกับหมวดหมู่ที่เลือก (ชั่วโมงที่ลดได้ หรือ % กระดาษที่ลด + จำนวนแผ่น/เดือน) และระบุเครื่องมือ Power Platform/AI ที่ใช้พัฒนา
  6. กด "สร้าง Project"
ฟิลด์ "ชั่วโมงที่ลดได้" และ "% กระดาษที่ลดได้" จำเป็นเฉพาะหมวดของตัวเองเท่านั้น ระบบไม่บังคับกรอกฟิลด์ที่ไม่เกี่ยวข้อง

5.2 Export ข้อมูลเป็น Excel

กดปุ่ม "Export Data" มุมขวาบนของหน้า — ระบบจะดาวน์โหลดไฟล์ .xlsx ของข้อมูล Project ทั้งหมดตามตัวกรองที่เลือกอยู่ (ตั้งชื่อไฟล์อัตโนมัติตามวันที่ เช่น TPS_Projects_2026-08-02.xlsx)

ปุ่มนี้ใช้งานได้เฉพาะบางบัญชีเท่านั้น (ดูรายชื่อในหมวด สรุปสิทธิ์การใช้งาน) — ผู้ใช้อื่นจะเห็นปุ่มเป็นสีเทา กดไม่ได้

6Citizen Developer Training

บันทึกประวัติการอบรม Power Platform ของพนักงานทั้ง 6 บริษัทในกลุ่ม

ระดับหลักสูตรจำนวนรอบ
L1 · BeginnerSmart Paperless Process Builder4 รอบ (Q3'26 – Q1-Q2'28)
L2 · IntermediateBusiness Automation App Builder3 รอบ (Q4'26 – Q1-Q2'28)
L3 · AdvancedAI-Assisted Web Application Development2 รอบ (Q1-Q2'27 – Q1-Q2'28)

6.1 เพิ่มประวัติการอบรม

  1. กดปุ่ม "+ เพิ่มประวัติการอบรม"
  2. เลือกบริษัทก่อน — ระบบจะกรองรายชื่อพนักงาน/แผนก/ส่วน/ฝ่าย ให้ตรงกับบริษัทนั้นโดยอัตโนมัติ (ข้อมูลมาจาก SharePoint Employee list จริง)
  3. เลือกชื่อ Course แล้วเลือก "รอบที่" — ตัวเลือกรอบจะเปลี่ยนตามหลักสูตรที่เลือก (แต่ละหลักสูตรมีจำนวนรอบไม่เท่ากัน)
  4. ระบบจะโชว์กล่องรายละเอียดหลักสูตร (ระดับ, เครื่องมือหลัก, เป้าหมาย, คุณสมบัติผู้เข้าอบรม) ให้ตรวจสอบก่อนกรอกต่อ
  5. กรอกวันที่เริ่ม/ถึงวันที่, เวลาเริ่ม/สิ้นสุด, ประเภท+ชื่อวิทยากร, ชื่อสถาบัน, รูปแบบการอบรม/สถานที่, ระยะเวลา
  6. กด "บันทึก" — ระบบจะเคลียร์เฉพาะข้อมูลตัวบุคคล (รหัสพนักงาน, ชื่อ) ส่วนข้อมูลรอบ/หลักสูตร/วิทยากรจะคงไว้ ช่วยคีย์คนถัดไปในคอร์สเดียวกันได้เร็วขึ้น

6.2 นำเข้าจาก Excel

สำหรับกรอกทีละหลายรายการ กดปุ่ม "Template" เพื่อดาวน์โหลดไฟล์ตัวอย่างก่อน กรอกข้อมูลตามคอลัมน์ในไฟล์ แล้วกด "อัปโหลดจาก Excel" เพื่อเลือกไฟล์ .xlsx/.xls นำเข้าทีเดียว

7Power Champion

ทะเบียนบุคลากรที่ได้รับการแต่งตั้งเป็น Power Champion ของแต่ละบริษัท — เป้าหมาย 6 คน/บริษัท/ปี รวม 18 คนภายใน FY'2028

คุณสมบัติและเงื่อนไข

  • Qualifications: สามารถสร้างหรือพัฒนางานโดยใช้เครื่องมือ Power Platform (MS Forms, Power Apps, Power Automate, Power BI, Database SharePoint List หรือ Excel)
  • Conditions: นำ Power Platform มาใช้พัฒนางานได้อย่างน้อย 1 Project (ลดเวลางาน, เพิ่มคุณภาพและกระบวนการทำงาน, ลดการใช้กระดาษด้วยระบบ Paperless)
  1. กดปุ่ม "+ เพิ่ม Power Champion"
  2. กรอกบริษัท/รหัสพนักงาน/ชื่อ/แผนก/ส่วน/ฝ่าย (กรองตามบริษัทเหมือนหน้า Training)
  3. เลือก Project Value (คุณค่าที่โดดเด่นของโครงการ), ผู้อนุมัติ, ปีที่ได้รับตำแหน่ง (FY)
  4. กรอกวันที่ได้รับคัดเลือก และรายละเอียดโดยสังเขป แล้วกดบันทึก

8Section Dashboard

9Executive Dashboard

ภาพรวมระดับผู้บริหาร ครอบคลุมทั้งกลุ่ม ATTG พร้อมมูลค่าที่ระบบสร้างคืนให้ธุรกิจ

  • สถิติ O365 License: จำนวนรวม, ค่าใช้จ่ายต่อปี, สัดส่วนที่ยังใช้งานไม่เต็มศักยภาพ, ROI Gap
  • มูลค่าที่ทำระบบ Automation / Paperless สร้างคืนให้ธุรกิจ (สะสมถึงปัจจุบัน — ไม่ใช่ยอดต่อปี)
  • กราฟเปรียบเทียบแต่ละบริษัท: จำนวน Project, Power Champions
  • Reduce Time by Division — เลือกบริษัทได้ ไล่เฉดสีตามความคืบหน้า (แดง = ยังไม่เริ่ม, ส้ม/เหลือง = กำลังไป, เขียว = ถึงเป้าหมาย)
  • สามารถกด Refresh มุมขวาบนเพื่อดึงข้อมูลล่าสุดได้ตลอดเวลา

13คำถามที่พบบ่อย

ทำไมข้อมูลบางหน้าโหลดช้าตอนเปิดครั้งแรกของวัน?

ฐานข้อมูลเป็นแบบ Serverless จะพักการทำงาน (Pause) อัตโนมัติเมื่อไม่มีคนใช้นาน 60 นาที การเปิดครั้งแรกหลังพักจึงอาจช้ากว่าปกติเล็กน้อย ลอง Refresh อีกครั้งถ้าข้อมูลดูไม่ครบ

ทำไมแก้ไขข้อมูลแล้วดูเหมือนไม่บันทึก?

อาจเกิดจาก session หมดอายุหลังไม่ได้ใช้งานนาน — ลอง Refresh หน้าเว็บแล้วลองแก้ไขอีกครั้ง ระบบจะแจ้งเตือนหากบันทึกไม่สำเร็จ

ข้อมูลบริษัท/แผนก/ฝ่ายผิด แก้ไขที่นี่ได้ไหม?

แก้ไม่ได้โดยตรงในระบบนี้ — ข้อมูลเหล่านี้ซิงก์มาจาก SharePoint Employee list ของบริษัททุกวัน ต้องแก้ที่ต้นทางแล้วรอรอบซิงก์ถัดไป

อยากเพิ่มประวัติการอบรมทีละหลายสิบคน ต้องกรอกทีละคนไหม?

ไม่ต้อง — ใช้ปุ่ม "Template" ดาวน์โหลดไฟล์ตัวอย่าง กรอกใน Excel แล้วอัปโหลดกลับเข้าระบบทีเดียวได้ (ดูหมวด 6.2)

14สถาปัตยกรรมระบบ (สำหรับทีม IT)

หมวดนี้สำหรับผู้ดูแลระบบ/ทีม IT เท่านั้น — อธิบายว่าระบบเชื่อมต่อกับ SharePoint และ Azure อย่างไร ผู้ใช้งานทั่วไปข้ามหมวดนี้ได้

ระบบใช้ Power Automate เป็น "สะพาน" อ่านข้อมูลจาก SharePoint แทนการต่อ Microsoft Graph API ตรงๆ เพราะ Connector ของ Power Automate ได้รับอนุมัติจาก Microsoft ไว้ล่วงหน้าแล้ว จึงไม่ติดปัญหา Admin Consent แบบที่เจอกับ Graph API

ลำดับการไหลของข้อมูล

  1. พนักงาน ATTG เข้าเว็บผ่าน browser ที่ https://tpsit.attg.co.th
  2. Azure Static Web App (React front-end + Entra ID Sign-in) เรียก /api/*
  3. Azure Functions (Backend API) อ่าน Master Data จาก Azure SQL ที่ sync ไว้แล้ว และอ่าน/เขียนข้อมูล Project / Training / Power Champion โดยตรง
